# Timezone Converter

This repository contains an interactive **Simple Timezone Converter**. It allows users to dynamically add or remove timezones and get instant feedback when converting between timezones in real-time.

It runs as a website, an installable offline PWA, and an Android app (Capacitor) ready for the Google Play Store.

## Features

* Add and remove multiple timezones for comparison
* Convert unix timestamps to readable dates and times
* Visualize time differences in a human-readable format (e.g., "8 hrs 33 mins ago" or "in 6 hrs 26 mins")
* Drag and reorder timezones for better organization
* Local storage support to save users' timezone selections
* Works fully offline — all libraries are bundled locally and a service worker precaches the app

## Demo

Experience the Timezone Converter in action by visiting the [live demo](https://theogibbons.github.io/timezone-converter/index.html). The intuitive interface allows you to quickly convert times between different timezones with real-time updates.

## Project layout

* `index.html` — the whole web app (served directly by GitHub Pages)
* `libs/` — vendored third-party libraries (jQuery, Select2, Moment Timezone); no CDN needed
* `manifest.webmanifest`, `sw.js`, `icons/` — PWA install + offline support
* `scripts/` — icon generation and the copy step that populates `www/` for Capacitor
* `android/` — native Android project generated by Capacitor
* `assets/` — source images for `@capacitor/assets` (Android launcher icons / splash screens)

## Building the Android app

Prerequisites: Node.js, JDK 21, and the Android SDK (platform 36). Set `sdk.dir` in `android/local.properties` (or `ANDROID_HOME`).

```bash
npm install
npm run android:bundle   # release .aab for the Play Store
npm run android:apk      # debug .apk for local testing (adb install)
```

Outputs:

* `android/app/build/outputs/bundle/release/app-release.aab` — upload this to the Play Console
* `android/app/build/outputs/apk/debug/app-debug.apk` — sideload for testing

Release signing uses `android/app/upload-keystore.jks` with credentials in `android/keystore.properties`. **Both files are gitignored — back them up somewhere safe.** If you lose the upload key you will have to reset it through the Play Console.

After changing the web app, re-run `npm run sync` (or either `android:*` script, which runs it for you) to copy the latest files into the native project.

### Publishing checklist (Play Console)

1. Create the app at https://play.google.com/console (app id: `io.github.theogibbons.timezoneconverter`).
2. Enroll in **Play App Signing** (default) and upload `app-release.aab`.
3. Provide store listing assets: `icons/icon-512.png` works as the 512×512 store icon; you'll also need a 1024×500 feature graphic and at least 2 screenshots.
4. Fill in the content rating questionnaire, data-safety form (the app collects no data), and privacy policy if required.
5. For each new release, bump `versionCode`/`versionName` in `android/app/build.gradle`.
